## 主な機能

- **テンキー (Numpad):**
  - 数字キー 0〜9、`.`、四則演算キー `+` `−` `×` `÷`
  - テンキーEnter (VK 269: Extended bit付加)、NumLock
  - オプションの拡張キー行（`Esc`, `Tab`, `BS`, `Del`）
  - キーの長押しによる自動リピート（初回450ms、間隔55ms）
  - 複数指による同時タッチ（高速打鍵対応）
- **トラックパッド (Trackpad):**
  - 1本指によるポインタ移動（加速度設定・速度調整対応）
  - タップによる左クリック、2本指タップによる右クリック
  - 2本指ドラッグによる縦・横スクロール（ナチュラルスクロール切替対応）
  - ダブルタップドラッグ（タップ直後の指スライドでドラッグ）
  - 下部の左右クリックボタン（非表示設定も可能）
- **テキスト入力バー (Keyboard Bar):**
  - バッチ送信モード（日本語IME等の変換確定後にまとめて送信）
  - 即時送信モード（キーを押すたびにPC側へリアルタイム送信）
  - 長文の自動チャンク分割（300文字毎、サロゲートペア対応）
- **2分割レイアウト (Split Layout - タブレット / 横画面対応):**
  - 画面幅600dp以上のタブレットで自動的にテンキーとトラックパッドの分割画面表示
  - 中央の仕切りつまみをドラッグして比率（15%〜85%）を自在に調整可能
  - 縦画面・横画面それぞれで分割方向（左右/上下）、配置（順序）、表示（両方/テンキーのみ/パッドのみ）を個別保存
- **3つの接続方式:**
  1. Wi-Fi / LAN (UDPポート 52111 によるPC自動検索対応)
  2. USBテザリング
  3. USBケーブル (`adb reverse tcp:52110 tcp:52110` による 127.0.0.1 接続)
- **テーマとカスタマイズ:**
  - ダークテーマ / ライトテーマ
  - 6色のアクセントカラー
  - キー間隔、角丸、文字サイズの調整
  - 画面常時点灯、触覚フィードバック (Haptic)

## 使い方

### 1. Windows側 (レシーバーの起動)

Windows PC上で添付の `receiver.py`またはインストーラーからダウンロードしたNumpadReceiver.exe を実行します。

```bash
python receiver.py
```

画面にPCのIPアドレス、ポート（標準: 52110）、および6桁のPINが表示されます。

### 2. Android側 (アプリの接続)

1. アプリを起動します。
2. 接続方式を選択します:
   - **Wi-Fi / LAN:** スマホとPCが同一Wi-Fiに接続されている状態で「**自動検索**」を押すか、PCに表示されているIPアドレスを入力します。
   - **USBテザリング:** スマホのUSBテザリングを有効化し、PCのIPを入力または自動検索します。
   - **USBケーブル (adb):** PCで `adb reverse tcp:52110 tcp:52110` を実行し、アプリ側で「USBケーブル (adb reverse)」を選択します。
3. PC画面に表示されているPINを入力し、「**接続**」をタップします。
4. 認証が完了すると自動的に操作画面に切り替わります。
